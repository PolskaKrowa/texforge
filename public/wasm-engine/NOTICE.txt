This directory contains the SwiftLaTeX WASM engines, vendored from the
SwiftLaTeX release package (https://github.com/SwiftLaTeX/SwiftLaTeX,
release v20022022, file 20-02-2022.zip).

Included files:
  - swiftlatexpdftex.js / swiftlatexpdftex.wasm   (PdfTeX engine)
  - swiftlatexxetex.js   / swiftlatexxetex.wasm   (XeTeX engine)

LOCAL PATCH (one line, both engine .js files)
  The original glue stores each file fetched from the texlive server under
  a path taken from the HTTP response header "fileid" — a header only the
  (now defunct) texlive2.swiftlatex.com server ever sent. Against a plain
  static file server every file would be written to the same path
  ("/tex/null"), clobbering each other. The patch falls back to the
  requested file name when the header is absent:
      getResponseHeader("fileid")  ->  getResponseHeader("fileid")||reqname

texlive/ — OFFLINE SNAPSHOT (curated, ~256 files)
  SwiftLaTeX's engine fetches its format file, packages and fonts at run
  time from https://texlive2.swiftlatex.com/, which has been offline for
  years (origin unreachable behind Cloudflare). This snapshot makes the
  built-in engine work fully offline. Contents:
    - pdftex/10/swiftlatexpdftex.fmt — a pdflatex format generated by the
      bundled engine itself (TeX Live 2021 kernel + expl3 + English
      hyphenation + Latin Modern), built via the engine's `compileformat`
      command with a local TeX Live 2021 mirror.
    - pdftex/<fmt-id>/<file> — the exact files the engine requests while
      compiling the built-in templates: LaTeX base classes, amsmath,
      geometry, hyperref (+ deps), beamer + pgf, booktabs, listings,
      xcolor, translator, CM / Latin Modern / AMS fonts (tfm + pfb),
      encoding vectors, pdftex.map and the graphics.cfg / hyphen.cfg /
      pdflatex.ini / pdftexconfig.tex bootstrap files.
  Files are taken from TeX Live 2021 (tlnet-final archive, packages:
  latex, latexconfig, latex-fonts, l3kernel, l3backend, hyphen-base,
  amsmath, amsfonts, amscls, cm, knuth-lib, ec, lm, tools, graphics,
  graphics-def, geometry, hyperref, url, iftex, oberdiek, etoolbox,
  auxhook, infwarerr, ltxcmds, kvsetkeys, kvdefinekeys, kvoptions,
  atbegshi, atveryend, pdftexcmds, intcalc, bitset, uniquecounter,
  stringenc, refcount, gettitlestring, beamer, translator, pgf, xcolor,
  booktabs, listings, pdfescape, firstaid, pdftex, unicode-data,
  glyphtounicode (in pdftex), calc (in latex)). They are distributed
  under the LaTeX Project Public License (LPPL) / their respective
  licenses; see https://tug.org/svn/texlive/trunk/ for sources.

  The generated .fmt embeds material from those LPPL-licensed sources;
  the bootstrap files in the snapshot (hyphen.cfg, pdflatex.ini,
  pdftexconfig.tex, graphics.cfg) are trivial configurations in the
  spirit of the originals (Thomas Esser's pdflatex.ini is public domain).

  Anything NOT in this snapshot (e.g. tikz front-ends, bibliography
  styles, other themes) is not available offline — install a system
  LaTeX engine (TeX Live / MiKTeX / tectonic) for full package coverage;
  TexForge uses it automatically when present.
